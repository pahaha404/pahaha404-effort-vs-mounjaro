# 노력하면 살이 빠질까? — 운동 vs 마운자로 인터랙션 웹게임 설계서

정보디자인 과제. 주제는 "노력으로 살을 뺄 수 있을까?".
장형우 교수(『비만록 — 나는 마운자로를 맞는 의사다』)의 주장 — 비만은 의지가 아니라
**세트 포인트** 문제이고 운동·식이는 보조요법 — 에서 출발한다.

- 평가 기준: ① 정보 전달·시각화가 메시지를 강조하는가 ② 불필요한 정보를 잘 뺐는가 ③ 도전적인가
- 과제 조건: **서로 다른 데이터셋 2개 이상을 연결**해 각각만 봐서는 안 보이는 관계를 드러낸다.
- 결론 문구는 쓰지 않는다. 플레이어가 두 캐릭터의 일생을 보고 스스로 판단한다.

## 2. 조합 인사이트 (각각만 봐서는 안 보이는 것)

1. **D3 + D4 vs D1** — MET로 계산한 소모 열량을 7,700 kcal/kg으로 나누면 "유령 바늘"이 쭉쭉 내려간다.
   그러나 똑같이 주 150분을 움직인 임상 위약군은 72주에 −3.1 %뿐이다. 두 바늘의 간격이 곧 **세트 포인트의 힘**이다.
2. **D1 + D2** — 약은 세트 포인트 자체를 내린다(−17.8 %p). 끊으면 52주 만에 +14 %가 되돌아온다. 몸이 기억하는 체중은 그대로다.
3. **D5 + D6** — 최저임금 10,320원과 공급가를 겹치면 "15 mg 유지 = 매주 16시간 알바"가 보인다. 노력이 사라진 게 아니라 **노력의 종류가 바뀐 것**이다.
4. **D7 + D9** — 한국 남자 생명표에 BMI별 HR을 곱하면 매주 두 캐릭터의 사망 확률이 달라진다. 결론은 쓰지 않고 묘비만 세운다.
5. **D8 + 나이** — 상단의 "같은 나이 남성 중 2단계 비만 n %"는 나이가 들수록 줄어든다. 살을 뺀 사람이 늘어서가 아니라, 세상에서 사라져서이기도 하다.
6. **D10 + D11** — 60세부터는 가만히 있어도 잉여 열량이 쌓인다. 늙을수록 같은 노력이 더 적게 돌아온다.

## 3. 게임 구조

### 3.1 인트로 모션 (약 25초, 아무 곳이나 클릭하면 건너뜀)

| 구간 | 내용 |
|---|---|
| 0–3 s | "우리는 왜 살을 못 뺄까요?" |
| 3–6 s | "노력이 부족해서?" |
| 6–11 s | 뽀글머리 남성 + 빨간 테이블. 72주 달력이 넘어가고 체중계 바늘이 살짝(−3.1 %) 움직인다 |
| 11–16 s | 주사기가 나타나고 바늘이 크게(−20.9 %) 움직인다 |
| 16–21 s | "노력이 부족한 걸까요, 아니면 노력으로는 안 되는 걸까요?" |
| 21–25 s | 남성이 좌우로 갈라지며 제목 「노력하면 살이 빠질까?」와 시작 버튼 |

### 3.2 메인 화면

- 좌우 분할, 1인 플레이. 같은 남성 두 명(25세, 105 kg, 키 166 cm, BMI 38).
- 시간 자동 진행: **1주 ≈ 2초**(1배속). 0.5×–32× 속도 조절.
- 끝 화면 없음. 캐릭터가 사망하면 그 자리에 묘비만 남고, 남은 캐릭터는 계속 진행한다.
- 상단: 나이 · 경과 주 · "같은 나이 한국 남성 중 2단계 비만 n %"(D8) · 속도 · ⓘ 데이터.

**왼쪽 — 노력하는 나 (주황·초록)**
- 운동 4종 선택(D3). 마우스를 **빠르게 클릭해야** 운동된다. 클릭 1회 = 10분.
- 피로 게이지: 클릭마다 차고 시간이 지나면 빠진다. 가득 차면 잠시 클릭이 먹지 않는다(숫자 없음).
- 보상심리 게이지: 운동할수록 차고, 간식 확률을 높인다(숫자 없음).
- 하루 두 끼 자동 식사 애니메이션(테이블 위 접시). 보상심리에 비례해 간식이 등장한다(D12·D13).
- 체중계: **유령 바늘**(칼로리 계산상 체중, 점선) vs **실제 바늘**.

**오른쪽 — 알바하고 주사 맞는 나 (보라·자주)**
- "알바 1시간" 버튼: +10,320원(D5).
- "주사 맞기" 버튼: 투여 시작/중단. 임상 증량 스케줄 2.5→5→7.5→10→12.5→15 mg(4주 간격, D1). "증량 멈춤"으로 유지 용량 선택 가능.
- 매주 펜 1개 값(박스값/4, D6)이 잔액에서 빠진다. 잔액 부족이면 투여가 끊기고 SURMOUNT-4 회복 곡선(D2)을 탄다.
- 잔액·투여 상태·용량 표시. 간식은 거의 없다(투여 중 간식 확률 × 0.15, 추정).
- 체중계: 실제 바늘만.

**공통**
- 60세 이후 기초대사 연 −0.7 %(D10)로 잉여 열량이 생겨 체중이 서서히 오른다.
- 매주 사망 확률 = q(나이)(D9) × HR(BMI)(D7) / 52. 사망하면 묘비: **나이, 누적 운동/알바 시간, 누적 지출**만.

우측 상단 버튼. §1 표의 데이터셋·출처·계산식을 그대로 보여준다. 추정치는 "추정" 배지.

## 4. 체중 모델 (`src/model.js`, 순수 함수)

주 1회 갱신. W = 실제 체중, G = 유령 체중, W₀ = 105 kg.

```
net_real  = 간식 kcal + 노화 잉여 kcal − 운동 kcal × (1 − compensation)
net_ghost = 간식 kcal + 노화 잉여 kcal − 운동 kcal
W'  = W + net_real / 7700 + κ · (W_set − W)
G'  = G + net_ghost / 7700
W_set = W₀ × (1 − s(용량)),  s(d) = drugShiftMax · d / (d + K50),  미투여 s = 0
κ   = kappaUp   (W < W_set, 세트 포인트로 되돌아감)
    = kappaDown (W > W_set, 약으로 내려감)
노화 잉여 = BMR(60세) × (1 − 0.993^(나이−60)) × 7   (60세 이후)
```

보정(`node tools/calibrate.js`):

| 파라미터 | 값 | 보정 근거 |
|---|---|---|
| compensation | 0.501 | D1 위약군: 주 150분 걷기, 간식 없음 → 72주 −3.1 % |
| kappaUp | 0.0195 /주 | D2: −20.9 %에서 중단, 생활습관 유지 → 52주 +14.0 % |
| kappaDown | 0.045 /주 | D1 15 mg 곡선 형태(24주 ≈ −10 %, 36주 ≈ −14 %) 수동 |
| drugShiftMax, K50 | 0.2507, 5.11 mg | D1: 15 mg −17.8 %p, 5 mg −11.9 %p (10 mg는 −15.9 vs −16.4 재현) |

검증: `node tests/model.test.js` — 72주 −3.1 %(주 150분), −17.8 %p(15 mg 투여 중), 중단 후 52주 +14 %.

## 5. 비주얼 규칙

- 배경: 밝은 크림(#FFF7EA). 글자: 짙은 갈색(#2B2118). 테이블: 빨강(#D7392B).
- 왼쪽: 주황(#F28C28)·초록(#3FA34D). 오른쪽: 보라(#7B3FBF)·자주(#C2399A).
- **남색·네이비·인디고·짙은 파랑 계열은 어디에도 쓰지 않는다.**
- 글꼴: Pretendard(CDN). 숫자는 tabular-nums.
- 캐릭터·테이블·음식·체중계·주사기·묘비는 모두 인라인 SVG. 체중에 따라 체형이 연속으로 변하고(BMI 기준 폭 스케일), 나이에 따라 머리색(검정→회색→흰색)과 주름이 변한다.
- 게이지는 숫자 없이 막대만. 결론 문구 없음.
- 모바일(375 px): 상하 분할(위 노력, 아래 주사). 상단 바 고정.

## 6. 기술

- 빌드 없는 정적 사이트. 루트 `index.html`, `src/` 아래 ES module JS와 CSS. 외부 의존은 Pretendard CDN뿐.
- `src/data.js` 상수 + 출처 주석, `src/model.js` 순수 함수, `tests/model.test.js`(node).
- Vercel: 저장소 import → Framework Preset "Other", 빌드 명령 없음, 출력 디렉터리 루트.
